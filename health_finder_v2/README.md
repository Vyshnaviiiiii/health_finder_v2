# 🏥 Health Finder

A Flutter + Firebase mobile app to find nearby clinics, pharmacies, blood banks, hospitals, and laboratories — built for India.

---

## 📱 Features

- **Nearby Search** — Find health services within 10km using GPS
- **Map View** — Google Maps with color-coded markers by type
- **Blood Bank Finder** — Filter by blood group availability
- **User Submissions** — Community-powered data (add new services)
- **Reviews & Ratings** — Leave ratings for services
- **One-tap Call & Directions** — Direct dial and Google Maps navigation
- **Auth** — Firebase Email/Password auth

## 🚀 Setup Guide

### 1. Prerequisites
- Flutter SDK (3.x+)
- A Firebase account
- A Google Cloud account (for Maps API)

### 2. Firebase Setup
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a new project (e.g. `health-finder`)
3. Enable **Authentication** → Email/Password
4. Enable **Cloud Firestore** → Start in test mode
5. Install FlutterFire CLI and run:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This auto-generates `lib/firebase_options.dart`

### 3. Google Maps Setup
1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Enable **Maps SDK for Android** and **Maps SDK for iOS**
3. Create an API key
4. Add to `android/app/src/main/AndroidManifest.xml`:
   ```xml
   <meta-data
       android:name="com.google.android.geo.API_KEY"
       android:value="YOUR_MAPS_API_KEY"/>
   ```
5. Add to `ios/Runner/AppDelegate.swift`:
   ```swift
   GMSServices.provideAPIKey("YOUR_MAPS_API_KEY")
   ```

### 4. Android Permissions
Add to `android/app/src/main/AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.CALL_PHONE"/>
```

### 5. iOS Permissions
Add to `ios/Runner/Info.plist`:
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>This app needs location to find nearby health services.</string>
```

### 6. Deploy Firestore Rules
```bash
firebase deploy --only firestore:rules
```

### 7. Run the App
```bash
flutter pub get
flutter run
```

## 🔥 Firestore Data Structure

```
health_services/
  {serviceId}/
    name: string
    address: string
    type: "clinic" | "pharmacy" | "bloodBank" | "hospital" | "laboratory"
    latitude: number
    longitude: number
    phone: string
    rating: number
    reviewCount: number
    isOpen: boolean
    openingHours: string
    bloodGroupsAvailable: string[]
    submittedBy: uid
    createdAt: timestamp
    
    reviews/
      {reviewId}/
        rating: number
        comment: string
        userId: uid
        createdAt: timestamp

users/
  {uid}/
    displayName: string
    email: string
    createdAt: timestamp
```
